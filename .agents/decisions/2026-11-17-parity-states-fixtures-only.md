# Parity states stage faults from fixtures only

Decision: the parity loop stages error, unavailable, offline, loading and empty states from fixtures and launch flags, and never by a write or a fault on a live connection. Options judged: a fault layer behind the guard proxy (drop, delay, refuse a read), a control tap on a live house with the proxy refusing the call, and fixtures. Fixtures won: every state the pairs need can be staged from the reference's gallery variables and the preview's flags, and a live fault risks the house.
