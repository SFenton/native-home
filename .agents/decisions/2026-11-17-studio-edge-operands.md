# Studio edge operands: authorable last-changed time, countdown, duration and truncate

Decision: native draws the Studio's edge operands generically (`sh.entity-time@1`, `sh.countdown@1`, `sh.duration-format@1`, `sh.math-truncate@1`): the time an entity last changed, a countdown to the second, a duration drawn as compact, clock, minutes and seconds or a span, and a number cut off instead of rounded. Options A, B and C were judged: A, authorable operands in Studio that native draws from the document; B, keep the old app's behaviours hand-built in native; C, leave them out. A is picked, against the recommendation, on the owner's request: "Instrument any logic that the previous native app was using via configuration in Studio." The countdown is the only operand that writes state on a clock: its 1 Hz tick starts on the first read, runs only while a page that reads it is on screen, and stops one tick after the last read, so a layout with no countdown costs nothing. A text that reads the second clock carries `updatesFrequently`, so VoiceOver does not announce every second; a visibility rule that reads it does not. The pick is item 4 of "Design picks" in `build/decisions/studio-logic.md`, by its content: make the edge logic authorable, keeping production's exact words and pixels.
