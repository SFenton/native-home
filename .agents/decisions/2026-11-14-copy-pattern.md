# The copy pattern: terms, case, budgets, ids and the pinned list

Decision: the app had no wording record, so the strings table (`sh.strings@1`) had no source for its catalog `maxLength`, id grammar or pinned list. Judged from the inventory in `build/research/sdui-review/15-rung0-strings-table.md` and a count of competing words in the live literals at `e6211d0b`; nothing was built and no string changed.
Replaces: none
Rule home: `.agents/patterns/copy.md`
Gate: matches_request=yes. The owner asked for the authored strings table in this review; the orchestrator's calls on note 15 set D1 to D3. `tools/jev_gate.py` was not run: nothing a person sees changes with this record.

- Terms. Where two words served one concept, the pick is the word the owner already approved in a pattern record, then the HIG's, then the majority. "Try Again" over "Retry" (the alerts record). "Couldn't" for a failed action, "Unable to Load" for a failed load and "Can't" for a standing block, over "Could not" and "failed" (the alerts and state-message records already use the first two for those two cases). "Choose" for an option over "Select" and "Pick" (32 distinct strings against 8). "Turn On" and "Turn Off" over "Enable" and "Disable" for a two-state thing (55 sites against 8). "this iPhone" and "this iPad" over "this phone" and "this device" (11 strings against 4; HIG Writing, "Write for how people use each device"). A progress label ends in the one-character ellipsis (HIG Buttons, "Checking out…"; 19 distinct strings against about 6). "Canceled", the serial comma and no "please" are the house's US style.
- Case. Each surface keeps the case most of its strings already have; the alerts record keeps alert titles and buttons. An accessibility hint takes no ending period (6 of 7 today).
- Budgets. Each is set above the longest default on that surface today and below what fits at the default text size on the narrowest window: tile verb 12 (longest 8), state word 16 (14), button 24 (18), alert title 40 (27, and 36 with a 28-character name), state title 32 (31), message 160 (153), status line 80 (59), hint 60 (36).
- Ids. `<area>.<component>.<slot>[.<role>]` beat `<surface>.<component>.<slot>`: a slot is by definition drawn on several surfaces, so a surface segment would be wrong for the second one; the surface stays a catalog field. The slot names the meaning so that a reword keeps its id.
- Pinned. Alarm and lock words as the orchestrator called (D2). Added by judgement: the garage door (an entry point like the lock), "Unavailable" and "Unknown" (a comforting word over a dead lock misleads), Cancel and destructive labels (HIG Alerts), and sentences that say what leaves the device or is erased. Other covers and valves lost the pin: wording them ("Raise", "Lower") is a fair house choice, so they carry the `safety` warning.
- Migration. Defaults move byte for byte, so the sweep is not a visible change. Every default this record would reword is listed for the owner and waits for propose-first.
