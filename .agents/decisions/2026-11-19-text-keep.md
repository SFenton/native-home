# Kept text is drawn and spoken exactly as live

Decision: A, plain. A text slot with `whenUnavailable: "keep"` whose source reads unavailable after an answer keeps drawing that answer, with no glyph, no grey and no VoiceOver cue. The owner picked it explicitly after seeing A, B and C with screenshots on iPhone, Duo and iPad.
Replaces: none
Rule home: .agents/design/kept-text.md
Gate: parked as `matches_request=unsure` on 2026-11-18; the owner then picked A, so `matches_request=yes`.

## Options judged

- A, plain. Won: kept text looks and sounds exactly like a live value, and tiles keep one frame height when a sensor drops.
- B, spoken. Lost: the element's VoiceOver value gained ", last known".
- C, marked. Lost: B plus a grey step and a leading `clock.arrow.circlepath` glyph. On iPhone and Duo folded the glyph wrapped "21.5 degrees" in a two-column tile, so tiles grew a line when a sensor dropped, and a Home Assistant restart would mark many slots at once.

The Designer's advisory lean was C (a reading hours old should not look current; HIG Color, "Avoid relying solely on color"). The owner overrode it. The A, B and C captures are kept outside the repo in `build/evidence/claude-text-keep/abc-archive/`.
