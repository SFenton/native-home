# Archive

> **What:** history only: superseded plans, work logs, audits and decision logs, kept to explain why a rule is the way it is. **Read when:** you need the reason behind a rule or a design; never to learn what to do now.

Agents read current rules and current designs. Nothing in this folder is a rule: if it disagrees with a rule doc, the rule doc wins. A rule doc links here only in a "why" line. See [docs-conventions](../workflow/docs-conventions.md#current-vs-history).
